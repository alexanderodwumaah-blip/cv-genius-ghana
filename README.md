# CV Genius Ghana 🇬🇭

A professional CV builder and refiner built specifically for Ghanaian students, graduates, national service applicants, and working professionals.

## Features

- **Refine Your CV** — Upload or paste your existing CV and get a professionally refined version tailored to your target opportunity (Corporate Job, National Service, Graduate Programme, Banking, Tech, Academia, NGO, and more)
- **Build From Scratch** — Fill in your details across 7 guided tabs and generate a perfectly formatted, print-ready CV
- **CV Score** — Get a 6-metric analysis of your CV covering contact info, structure, action language, quantification, date consistency, and length
- **Cover Letter Generator** — Instantly generate a tailored, professional cover letter for any opportunity type
- **CV Tips** — 7 learning tabs including Foundational Rules, Writing Tips, Action Verbs reference, and tips by opportunity type (based on SEO Africa CV Writing Guidelines)
- **Sample CVs** — View and download sample CVs across Finance/Banking, Engineering, National Service, and Postgraduate profiles

## Tech Stack

Pure HTML, CSS, and JavaScript — no frameworks, no build tools, no backend required. Deploy anywhere as a static site.

## Live Demo

Deployed on Vercel: [cv-genius-ghana.vercel.app](https://cv-genius-ghana.vercel.app)

## Local Development

Just open `index.html` in a browser, or serve with any static server:

```bash
npx serve .
# or
python -m http.server 5500
```

## Deployment

This is a static site — deploy directly to Vercel, Netlify, GitHub Pages, or any static host with zero configuration.
